
# ✈️ Airline Satisfaction Prediction

A machine learning web application that predicts airline passenger satisfaction using passenger and flight-related information. The project combines CatBoost and LightGBM models and provides predictions through a simple Flask web interface.

## 🚀 Live Demo

**Try the application:** [Airline Satisfaction Prediction](https://airline-satisfaction-prediction.onrender.com)

**GitHub Repository:** [View Source Code](https://github.com/rahuldungdung809-alt/airline-satisfaction-prediction)

## 📌 Project Overview

The goal of this project is to predict whether an airline passenger is satisfied with their flight experience based on available passenger and travel information.

The project uses machine learning classification models and a blended prediction approach to improve validation performance. The trained models are integrated into a Flask application and deployed using Docker on Render.

## ✨ Features

- Predict airline passenger satisfaction through a web interface.
- Use trained CatBoost and LightGBM models.
- Combine predictions from both models using a 50/50 blend.
- Display prediction results through a Flask application.
- Run the application locally or with Docker.
- Access the deployed application through a public URL.

## 🧠 Machine Learning Models

The project uses the following models:

- **CatBoost Classifier** — handles categorical features effectively.
- **LightGBM Classifier** — provides efficient gradient boosting.
- **Blended Model** — combines predictions from CatBoost and LightGBM.

The final prediction is generated by averaging the predicted probabilities of both models.

## 📊 Model Performance

The following results were obtained during model validation.

| Model | Validation ROC-AUC |
|---|---:|
| CatBoost | 0.957720 |
| LightGBM | 0.957672 |
| 50/50 Blended Model | **0.957895** |

**Evaluation metric:** ROC-AUC (Area Under the Receiver Operating Characteristic Curve).

The blended model achieved the highest ROC-AUC among these three validation results.

> Note: Validation ROC-AUC and Kaggle competition scores are different measurements and should not be compared as if they were the same evaluation result.

## 📂 Dataset

This project is based on the Kaggle Playground Series competition for predicting airline satisfaction.

The dataset contains passenger and flight-related information used to train classification models.

**Dataset source:** [Kaggle — Predicting Airline Satisfaction](https://www.kaggle.com/competitions/playground-series-s6e10)

## ⚙️ Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/rahuldungdung809-alt/airline-satisfaction-prediction.git
```

### 2. Open the project directory

```bash
cd airline-satisfaction-prediction
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Start the application

```bash
python app.py
```

Open your browser at:

```text
http://127.0.0.1:5000
```

The application uses the saved model artifacts, so make sure the required files are present in the `artifacts/` directory.

## 🐳 Run with Docker

Docker can run the application in a container with its required dependencies.

### 1. Build the Docker image

Run this command from the project root:

```bash
docker build -t airline-satisfaction-prediction .
```

### 2. Start the container

```bash
docker run --rm -p 10000:10000 airline-satisfaction-prediction
```

### 3. Open the application

Visit:

```text
http://localhost:10000
```

To stop the container, press `Ctrl + C` in the terminal where it is running.

## ☁️ Deployment

The application is deployed on Render using Docker.

**Live application:** https://airline-satisfaction-prediction.onrender.com

The Docker image includes the Flask application, trained model artifacts, and required Python dependencies. Gunicorn serves the application in the deployment environment.
